# Portofolio Profesional — Malik Jabbar ('26)

Website portofolio bergaya **Playful Editorial & Lanyard ID Card** (terinspirasi dari referensi desain *Shourya Khanna '25*), dilengkapi foto *cutout* transparan di depan tipografi `PoRtfoLio '26`, kartu *ID Badge* gantung interaktif, matriks resume 3 kolom, serta 5 kolom warna vertikal `CONTENT 01–05`.

## Daftar File di Dalam Paket Ini
- `index.html` — Halaman utama lengkap dengan profil, pengalaman kerja, pendidikan, kontak, dan 8 sertifikasi Malik Jabbar.
- `style.css` — Desain editorial terang (*warm off-white paper*), animasi huruf `PoRtfoLio`, kartu *lanyard*, dan 5 kolom *strip* warna.
- `script.js` — Navigasi *mobile* dan animasi *scroll reveal*.
- `malik-hero.png` — Foto *cutout* transparan Malik Jabbar untuk bagian *Hero* di depan teks `PoRtfoLio`.
- `malik-idcard.jpg` — Foto potret Malik Jabbar untuk kartu *ID Lanyard*.
- `vercel.json` — Konfigurasi *routing* dan keamanan *headers* siap pakai untuk Vercel.

## Cara Deploy ke GitHub & Vercel (Anti Error)
1. **Ekstrak File ZIP:** Ekstrak `portofolio-malik-jabbar-v2.zip` di laptop atau HP Anda.
2. **Upload ke GitHub:**
   - Masuk ke [github.com/new](https://github.com/new), buat repository baru (misalnya `portofolio-malik-jabbar`), pilih **Public**, lalu klik **Create repository**.
   - Klik tautan **"uploading an existing file"**.
   - Tarik dan masukkan **semua 7 file** (`index.html`, `style.css`, `script.js`, `malik-hero.png`, `malik-idcard.jpg`, `vercel.json`, `README.md`) secara langsung ke halaman upload (pastikan semua file berada di tingkat utama, bukan di dalam sub-folder).
   - Klik tombol hijau **Commit changes**.
3. **Deploy di Vercel:**
   - Masuk ke [vercel.com](https://vercel.com) dengan akun GitHub Anda.
   - Klik **Add New...** -> **Project** -> Klik **Import** pada repository `portofolio-malik-jabbar`.
   - Biarkan **Framework Preset** pada pilihan **Other**, lalu klik **Deploy**.
